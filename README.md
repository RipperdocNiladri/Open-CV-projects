# ⚙️ Installation

## 1. Clone the Repository

```bash
git clone https://github.com/RipperdocNiladri/Open-CV-projects.git
```

Navigate into the repository:

```bash
cd Open-CV-projects
```

---

## 2. Create a Virtual Environment

It is recommended to use a virtual environment for Python projects.

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### Linux / macOS

```bash
python3 -m venv venv
source venv/bin/activate
```

---

## 3. Install Dependencies

Install OpenCV:

```bash
pip install opencv-python
```

If a project contains additional dependencies, install them according to that project's README.

---

# ▶️ Running a Project

Navigate to the project directory:

```bash
cd project_01
```

or:

```bash
cd project_02
```

Run the Python program:

```bash
python face_detection.py
```

or:

```bash
python face_with_mask.py
```

> Make sure your webcam is connected and accessible by OpenCV when running real-time projects.
